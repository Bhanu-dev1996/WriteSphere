# Responsive Design

## Breakpoints

| Breakpoint | Width     | Target        |
| ---------- | --------- | ------------- |
| sm         | ≥640px    | Large phones  |
| md         | ≥768px    | Tablets       |
| lg         | ≥1024px   | Laptops       |
| xl         | ≥1280px   | Desktops      |

## Layout Adaptations

### Home Page

| Element        | Mobile          | Tablet             | Desktop              |
| -------------- | --------------- | ------------------ | -------------------- |
| Header         | Compact, menu   | Full nav           | Full nav             |
| Hero           | Single column   | Single column      | Featured + sidebar   |
| Blog Grid      | 1 column        | 2 columns          | 3 columns            |
| Sidebar        | Hidden          | Hidden             | Visible (sticky)     |
| Footer         | Stacked         | 2 columns          | 4 columns            |

### Blog Details

| Element        | Mobile          | Tablet/Desktop     |
| -------------- | --------------- | ------------------ |
| Cover Image    | Full width      | Full width (max-h) |
| Content        | Full width      | Max-width 720px    |
| Sidebar        | Hidden          | Visible right      |

### Dashboard

| Element  | Mobile          | Desktop        |
| -------- | --------------- | -------------- |
| Sidebar  | Slide-over menu | Fixed left     |
| Content  | Full width      | Remaining width |
| Cards    | 1 column        | 2-3 columns    |

## Touch Targets

- Minimum 44x44px for interactive elements on mobile
- Adequate spacing between clickable items
- Swipe gestures for mobile (future)
