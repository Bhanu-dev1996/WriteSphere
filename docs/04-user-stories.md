# User Stories

## Authentication

- As a **guest**, I want to register so I can become an author.
- As a **registered user**, I want to log in so I can access my dashboard.
- As a **registered user**, I want to log out so my session is secure.
- As a **registered user**, I want to reset my password if I forget it.
- As a **registered user**, I want to change my password for security.

## Blog Management

- As an **author**, I want to create a blog post with a rich editor.
- As an **author**, I want to save my work as a draft and publish later.
- As an **author**, I want to edit my published posts.
- As an **author**, I want to delete my posts.
- As an **author**, I want to add a cover image to my blog.
- As an **author**, I want to categorise my posts with tags.

## Comments

- As a **reader**, I want to comment on a blog post.
- As a **reader**, I want to reply to existing comments.
- As a **commenter**, I want to delete my own comment.

## Reactions

- As a **reader**, I want to react to a blog post with Like, Heart, or Celebrate.
- As a **reader**, I want to remove my reaction.

## Follow System

- As a **reader**, I want to follow authors whose content I enjoy.
- As a **reader**, I want to unfollow authors.
- As an **author**, I want to see my follower count.

## Notifications

- As a **user**, I want to be notified when someone follows me.
- As a **user**, I want to be notified when someone likes my post.
- As a **user**, I want to be notified when someone comments on my post.
- As a **user**, I want to mark notifications as read.

## Bookmarks

- As a **reader**, I want to bookmark blogs to read later.
- As a **reader**, I want to view all my bookmarks.
- As a **reader**, I want to remove a bookmark.

## Reading History

- As a **reader**, I want to see my recently viewed blogs.
- As a **reader**, I want to continue reading where I left off.

## Search

- As a **reader**, I want to search for blogs by title, tags, author, or category.
- As a **reader**, I want to filter search results by latest, popular, most liked, or most commented.

## Dashboard

- As an **author**, I want a dashboard showing my blogs, drafts, followers, and notifications at a glance.
