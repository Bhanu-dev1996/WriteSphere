# Navigation

## Header Navigation

### Desktop

```
[Logo]  [Search...]  [Home] [Categories▾]  [Create Post▸]  [🔔]  [👤▾]
```

- Logo links to home
- Search is an expandable input
- Categories dropdown lists all categories
- Create Post button (authenticated only) links to create blog
- Notification bell (authenticated only) shows unread count
- User dropdown (authenticated only): Dashboard, Profile, Bookmarks, Logout

### Mobile

```
[☰]  [Logo]  [🔔]  [👤]
```

- Hamburger menu opens a slide-over sheet with all navigation items
- Search is accessible via a search icon in the header
