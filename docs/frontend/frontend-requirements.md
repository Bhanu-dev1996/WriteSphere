# Frontend Requirements

## Core Requirements

- React 19 SPA with TypeScript
- Vite build tool
- Tailwind CSS v4 for styling
- shadcn/ui + Radix UI for component primitives
- React Router DOM v7 for routing
- TanStack Query for server state management
- Zustand for global UI state
- React Hook Form + Zod for forms
- Axios for HTTP client
- Framer Motion for animations
- React Hot Toast for notifications
- Lucide React for icons
- React Helmet Async for SEO meta tags

## Performance Requirements

- Lazy loading for routes (React.lazy + Suspense)
- Image lazy loading and optimization
- Infinite scroll for paginated lists
- Debounced search input
- Memoized components (React.memo, useMemo, useCallback)

## Accessibility Requirements

- Semantic HTML throughout
- ARIA labels on interactive elements
- Keyboard navigation support
- Focus management in modals and dialogs
- Screen reader friendly announcements

## Responsive Requirements

- Mobile-first design
- Breakpoints: sm (640px), md (768px), lg (1024px), xl (1280px)
- Collapsible mobile navigation
- Touch-friendly interactive elements

## SEO Requirements

- Dynamic meta tags per page (React Helmet Async)
- OpenGraph and Twitter Card meta tags
- Structured data (JSON-LD) for blog posts
- Sitemap.xml generation
- Robots.txt
- Semantic heading hierarchy (h1-h6)
